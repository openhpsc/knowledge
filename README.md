# OpenHPSC Knowledge

A curated collection of papers, reports, manuals, presentations, and technical
notes supporting OpenHPSC research and development.

## Topics

| Folder | Content |
| --- | --- |
| [HPSC](hpsc/) | NASA/Microchip HPSC architecture and published research |
| [Architectures](architectures/) | Processor architectures and open hardware platforms |
| [Fault tolerance](fault-tolerance/) | Detection, correction, redundancy, and recovery |
| [Radiation](radiation/) | Radiation effects, characterization, and test reports |
| [Software](software/) | RTEMS, development tools, and system software |

## Adding resources

Place each resource in the most relevant folder. Record its title, authors,
publication date, original URL, and redistribution terms in that folder's README.

Prefer original sources. Upload third-party files only when redistribution is
permitted. Third-party material retains its own copyright and license; this
repository's license does not override those terms.
